# Auto 카메라 라인트레이서

휴대폰 후면 카메라로 바닥의 검정 테이프를 보고, 블루투스로 SPIKE Prime 허브(Auto)를 직접 조종하는 웹페이지.
GitHub은 페이지 파일을 받아오는 곳일 뿐, 주행 중 통신은 **휴대폰 ↔ 허브 블루투스 직통**. 카메라 영상은 휴대폰 밖으로 나가지 않음.

- 필요: **안드로이드 휴대폰 + Chrome** (아이폰은 웹 블루투스 미지원), 공식 펌웨어 그대로의 SPIKE Prime 허브
- 허브 포트: A, B = 바퀴 모터 (방향은 페이지에서 맞춤)
- 허브 슬롯 사용: 19번 = 주행 프로그램, 18번 = 명령 파일 (0번 등 다른 슬롯은 건드리지 않음)

## GitHub Pages에 올리기 (처음 한 번)

1. github.com 로그인 → 오른쪽 위 **+ → New repository** → 이름 예: `auto-line` → **Public** → **Create repository**
2. 만들어진 화면의 **uploading an existing file** 클릭 → 이 폴더의 파일 6개를 끌어다 놓기 → **Commit changes**
   `index.html` `core.js` `hub_follow.py` `sw.js` `manifest.webmanifest` `icon.svg`
3. 저장소 **Settings → Pages** → Branch를 **main**, 폴더 **/(root)** → **Save**
4. 1~2분 뒤 주소가 생김: `https://<내 아이디>.github.io/auto-line/`

고칠 때는 바뀐 파일만 같은 저장소에 다시 업로드하면 됨 (휴대폰은 다음에 열 때 새 버전을 받음).

## 휴대폰에서 쓰기

1. Chrome으로 위 주소 열기 → (선택) 메뉴 ⋮ → **홈 화면에 추가** — 한 번 열고 나면 인터넷 없이도 열림
2. 허브 켜기 (노트북·SPIKE 앱과 연결돼 있으면 해제 — 허브는 한 번에 한 기기만)
3. **① 허브 연결** → 목록에서 **Auto** 선택 → 권한(근처 기기/위치) 허용 → 허브가 "삐삑" 하면 준비 완료
4. **② 카메라 켜기** → 카메라 권한 허용
5. 처음 한 번: **바퀴 방향 맞추기** 열고 ▲/⟲ 버튼을 눌러보며, 반대로 가면 체크
6. 테이프 위에 올려두고 **▶ 출발**, 멈출 땐 **■ 정지**

## 휴대폰 거치 팁

- 후면 카메라가 차 **앞쪽 바닥을 비스듬히(30~45°)** 내려다보게, 화면에서 테이프가 **아래쪽 가운데**에 오도록
- 화면의 **빨간색 = 검정으로 인식된 부분**, **초록 점 3개 = 찾은 선 위치**. 점이 테이프 위에 있으면 정상
- 바닥 무늬까지 빨갛게 칠해지면 "검정 기준 자동"을 끄고 기준값을 낮추기
- 지그재그로 흔들리면 "조향 세기"를 낮추거나 "흔들림 억제"를 올리기, 커브에서 놓치면 속도를 낮추기

## 안전장치

- 명령이 0.7초 끊기면 허브가 스스로 정지 (휴대폰 꺼짐·연결 끊김·앱 전환)
- 페이지를 벗어나거나 화면이 꺼지면 정지, 카메라가 멈춰도 정지
- 선을 잃으면 1초 동안 마지막으로 본 쪽으로 천천히 돌며 찾고, 못 찾으면 정지
- 허브 가운데 버튼을 누르면 프로그램 즉시 종료
